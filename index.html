Red Dwarf guide

Type naturally

Use the keypad or your keyboard. Expressions such as 2π + sqrt(81) work directly.

Scientific functions

Trigonometry follows the selected DEG/RAD mode. Powers, logarithms, factorial and percentages are supported.

Private by design

History, memory and preferences remain in this browser. No account or network request is used for calculations.

Install and go offline

Install Red Dwarf from the header or browser menu. The application works after the signal disappears.
